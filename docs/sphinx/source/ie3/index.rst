IE3 — Campaign Creative
========================

IE3 generates promotional copy and images when EEP receives a ``PROMOTE``
decision. It uses the **Anthropic Claude API** for text and **DALL-E / Replicate**
for images, then optionally publishes to social media.

Runs on **port 8003** (owner: Mohammad Farhat).
