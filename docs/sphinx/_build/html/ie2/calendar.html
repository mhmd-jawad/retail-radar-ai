Retail Event Calendar¶

Shared Lebanon retail event calendar for IE2.

This module keeps a small set of fixed-date retail windows and exposes helpers for date-based event proximity scoring and event-aware rule logic.

get_event_proximity_score(target_date, lookahead_days=14)[source]¶

Return the maximum event proximity score for a given date.

Checks both the current year and the following year so that year-boundary events are captured correctly.

Parameters:

  • target_date (date) – The date to score.

  • lookahead_days (int) – How many days ahead of each window to start scoring.

Returns:

Maximum proximity score across all known event windows, in [0.0, 1.0].

Return type:

float

get_active_or_upcoming_event(target_date, lookahead_days=14)[source]¶

Find the active or nearest upcoming event window for a given date.

If target_date falls inside an event window the closest-to-peak window is returned with days_until = 0. Otherwise, the nearest upcoming window within lookahead_days is returned.

Parameters:

  • target_date (date) – The date to evaluate.

  • lookahead_days (int) – How many days ahead to look for upcoming events.

Returns:

A tuple of (event_window, days_until_start). Both values are None when no relevant event is found.

Return type:

tuple[RetailEventWindow | None, int | None]
